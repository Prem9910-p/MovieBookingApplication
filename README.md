# Movie Ticket Booking System

A backend application for a Movie Ticket Booking System developed using **Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL**. The project provides RESTful APIs to manage movies, theatres, screens, showtimes, seats, and ticket bookings.

## Features

- **Movie Management:** Add, update, delete, and retrieve movie details.
- **Theatre Management:** Manage theatres, screens, and seating arrangements.
- **Show Management:** Schedule movie shows with dates, times, and ticket prices.
- **Seat Selection:** View available seats for a particular show.
- **Ticket Booking:** Book tickets and retrieve booking details.
- **Booking Management:** View booking history and cancel reservations.
- **Database Integration:** Persist application data using MySQL and Spring Data JPA.
- **RESTful APIs:** Expose endpoints for testing and integration with frontend applications.

## Tech Stack

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST APIs
- Postman

## Architecture

The application follows a layered architecture:

- **Controller Layer:** Handles HTTP requests and responses.
- **Service Layer:** Implements business logic.
- **Repository Layer:** Performs database operations.
- **Entity Layer:** Defines database entities and relationships.
